## Area A — Engine (runner + gates + content pipeline)

### A-1 [S2] `frontmatter.topic` is never validated against the folder slug
[src/lib/content.ts:96-131](src/lib/content.ts) derives `topicSlug` from the path; [src/lib/content.ts:178](src/lib/content.ts) filters experiments by that path-derived slug. The `topic` field declared in frontmatter ([src/lib/schema.ts:42](src/lib/schema.ts)) is read into validated data and otherwise ignored. An author writing `topic: 'banana'` in a lab under `mekanik/<slug>/` gets silently shrugged off.
**Decide:** drop the field, or add an equality assertion.

### A-2 [S2] `Phase.id` is unconstrained `z.string()`
[src/lib/schema.ts:31-37](src/lib/schema.ts). The 7 canonical phase ids from SPEC §2 (memory `feedback_phase_ids`) aren't enforced — a typo like `udforsk` would load. Test labs use the canonical 7, so a soft enum-with-warning for non-`test`-tagged labs would catch typos without breaking the testbed.

### A-3 [S3] Gate-kind enumeration is duplicated
Zod `Gate` discriminated union ([src/lib/schema.ts:3-28](src/lib/schema.ts)) lists 8 kinds; `AUTHORABLE_GATE_KINDS` ([src/lib/content.ts:13-19](src/lib/content.ts)) lists 5 of them as authorable for non-test labs. Different purposes, won't drift silently — but a 9th gate would need updates in two places. Could be derived: `AUTHORABLE_GATE_KINDS` could be `Gate['type']` minus a denylist.

### A-4 [S3] Magic string `'__none'`
Appears in [src/lib/simulations.ts:16](src/lib/simulations.ts), [src/lab-guide/LabGuide.tsx:17](src/lab-guide/LabGuide.tsx) (doc comment), and inline in any theory-only lab's frontmatter (e.g. [src/content/experiments/test-labs/framework-test/index.ts:15](src/content/experiments/test-labs/framework-test/index.ts)).
**Recommend:** export `NO_SIMULATION = '__none'` from `sim-contract`.

### A-5 [verified ✓]
Persistence shape (`htxlabs:state:${experimentId}`, [src/lab-guide/runner.ts:45](src/lab-guide/runner.ts)), silent wipe with `console.info` ([src/lab-guide/RunnerContext.tsx:75](src/lab-guide/RunnerContext.tsx)), navigation asymmetry ([src/lab-guide/gates.ts:78](src/lab-guide/gates.ts)), `inquiryFreeAdvance` open-mode escape ([src/lab-guide/gates.ts:18](src/lab-guide/gates.ts)), and the ref+`setTick` widget-state path ([src/lab-guide/RunnerContext.tsx:88-163](src/lab-guide/RunnerContext.tsx)) all match CLAUDE.md and memory.
